**ACE CBRN** adds chemical warfare agents and protective gear.

Arsenal Items:
- Atropine/Oxime injector
- M50 protective mask
- Sarin nerve agent mortar shells

## Chemical Agents
### Phosgene-Chlorine Mixture

Pale green-yellow choking agent, which causes extensive damage to respiratory system and eventually pulmonary edema.

### Sarin

A volatile, colorless organophosphate-based nerve agent, which causes muscle spasms and respiratory paralysis in less than a minute of exposure. Sarin-based shells hit short (dissipates within minutes), but hard (fast-acting).

## Settings

Summary of settings that can be modified in the server config:

| Field                                 | Value                | Description                                        |
| ------------------------------------- | -------------------- | -------------------------------------------------- |
| `m_bFullParalysisForAIEnabled`        | Type: `bool`<br />Default: `false` | AI will die instead of becoming paralyzed if false |

<br />

Template for the `missionHeader` in a server config:
```
"missionHeader": {
    "m_ACE_Settings": {
        "m_ACE_CBRN": {
            m_bFullParalysisForAIEnabled": false
        }
    }
}
```
