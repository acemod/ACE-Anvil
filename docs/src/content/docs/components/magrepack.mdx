**Magazine Repack** modifies the base game's magazine repacking:
- Faster repacking for ammunition belts
- Configurable time scales


## Settings

Certain aspects of this mod can be configured in the mission header section of a server config file. An overview of available fields is given below in the table:

| Field                                 | Value                | Description                                        |
| ------------------------------------- | -------------------- | -------------------------------------------------- |
| `m_fPackingTimeScale`                 | Type: `float`<br />Range: 0 to ∞<br />Default: `1.0` | Scale for time it takes to transfer a round between magazines. |
| `m_fBeltPackingTimeScale`             | Type: `float`<br />Range: 0 to ∞<br />Default: `0.1` | Scale for time it takes to transfer a round between ammunition belts. |
<br>

Example for the `missionHeader` in a server config:
```
"missionHeader": {
    "m_ACE_Settings": {
          "m_ACE_MagRepack_Settings": {
            "m_fPackingTimeScale": 1.0,
            "m_fBeltPackingTimeScale": 0.1
        }
    }
}
```
